钉钉

如何获取？ ↗
在钉钉开放平台创建企业内部应用，添加机器人能力，消息接收模式选 Stream 模式
  • CorpId（企业 ID）来自开放平台应用详情页。
  • AppKey（Client ID）与发送接口中的 Robot Code 使用同一值。
  • 机器人能力已开启，消息接收方式为 Stream。
  • 事件订阅已勾选消息接收相关事件，并已保存。
  • 后台改配置后，务必发布最新应用版本再测试。

一次填写即可，系统会按同值处理 Robot Code

若不填，默认复用 AppKey；若填写则优先使用该值

企业微信

如何获取？ ↗
在企微智能机器人页面创建 API 模式 + 长连接机器人，填写机器人 Bot ID + Secret
  • 机器人模式选择 API + 长连接，状态为启用。
  • Bot ID 通常以 aib 或 aib_ 开头；不要填写 corpId 或自建应用 Secret。
  • 企微后台事件权限和可见范围已完成配置。
  • 变更权限后，重新保存并重启服务后再验证消息。
